# نظام إدارة الاجتماعات واللجان — نسخة تجريبية (Demo)

نسخة تجريبية لتوضيح فكرة نظام يدير دورة حياة الاجتماع كاملة: من المسودة، إلى الدعوات، ثم المحضر والقرارات، وصولاً إلى التوقيع الحي والأرشفة ومتابعة التنفيذ.

📱 يعمل على الكمبيوتر والتابلت والموبايل (على الموبايل تظهر القائمة أسفل الشاشة والجداول تتحول لبطاقات).

> ⚠️ هذه نسخة عرض فقط. البيانات وهمية وتُحفظ في متصفح كل مستخدم (localStorage)، ولا يوجد سيرفر ولا أمان حقيقي.

## طريقة التجربة
اختر الشخص من قائمة **"الدخول باسم"** أعلى الصفحة، ولاحظ كيف تتغير الشاشات والأزرار حسب الصلاحية:

| الشخص | الدور |
|---|---|
| م. سامر الخطيب | مدير النظام: يدير اللجان والأعضاء وسجل التدقيق، ولا يرى الاجتماعات "سري جداً" |
| د. ليلى حداد | رئيسة لجنة المشتريات ومجلس الإدارة: تعتمد الاجتماعات والمحاضر |
| أحمد العمري | منسق لجنة المشتريات: ينشئ الاجتماعات ويحرر المحاضر ويطبع ويؤرشف |
| خالد النسور | عضو في المشتريات **ومنسق** في التحول الرقمي (الصلاحية حسب اللجنة) |
| رنا الزعبي | عضو، ومسؤولة عن تنفيذ قرارات |

## مراحل الاجتماع
مسودة → اعتماد الرئيس → الدعوات وتأكيد الحضور → الانعقاد والتصويت → تحرير المحضر → اعتماد المحضر → الطباعة والتوقيع الحي (مع QR وبصمة) → الأرشفة والإقفال → متابعة القرارات

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، مثلاً `meeting-system-demo`.
2. ارفع الملفين `index.html` و`README.md` (من زر **Add file → Upload files**).
3. من **Settings → Pages** اختر: `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة إلى دقيقتين يصبح الرابط جاهزاً بالشكل:
   `https://USERNAME.github.io/meeting-system-demo/`

لإعادة البيانات التجريبية لوضعها الأصلي: زر **"إعادة البيانات التجريبية"** أسفل القائمة الجانبية.
